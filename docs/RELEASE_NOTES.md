First public release of CustomSuno for Windows and Linux.

- Compact toolbar and tool panels with English and German support.
- Suno tabs with persistent sign-in, downloads, optional mods, plugins, and themes.
- Media library with trimming, merging, metadata, and local audio processing.
- WAV, MP3, and M4A export.

## Downloads

- **Windows x64:** run the `x64-setup.exe` installer. WebView2 is installed if needed. The installer is unsigned.
- **Linux x64:** install the `.deb` on Ubuntu 22.04 or newer, or make the AppImage executable and run it. If FUSE is unavailable, use `--appimage-extract-and-run`.
- **SHA256SUMS.txt:** checksums for release assets.
